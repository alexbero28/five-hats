# Derive, don't recall

**The rule:** state is COUNTED, never remembered. If you are about to say what is true right now,
run the thing that derives it first — in this turn, not from earlier in the conversation.

## Why this exists

On 2026-08-20 a session opened by telling the owner "nothing has ever been mailed." Eight dispute
letters were out, two clients were live, twenty-two positive outcomes were on record, and four
statutory clocks were running. The false claim came from a memory file and a session-start hook —
and it appeared in **four** different files, one of which contradicted itself in the same document
because a correction was pasted at the top and the original line was never deleted.

Acting on it would have meant re-disputing accounts with live clocks. That is not an embarrassment,
it is regulatory exposure on a real person's file.

**A stale fact is worse than a missing one.** Missing prompts a question. Stale gets acted on.

## What to do

1. **Identify the deriving command** for this domain — the one that counts rather than remembers.
2. **Run it this turn.** Not "we established earlier." Earlier may be wrong, and earlier may be a
   different day.
3. **If what you recall disagrees with what it prints, the command wins — and say so out loud.**
   The disagreement is itself information: something wrote a claim that is no longer true.

Name the deriving command for each domain you work in. Yours will differ; the shape does not:

| Question | Run |
|---|---|
| Where does each active job stand? | your ledger's status command |
| What is running out of time? | your deadline / clock command |
| What can go out, and what is blocked? | your queue command |
| Is everything healthy? | your board or health command |
| Is anything running ungoverned? | your coverage scan |
| What is actually deployed right now? | the project's own status command |

For a domain with no deriving command, **that is the finding** — say so, and treat every state
claim about it as unverified.

## The tell

You are about to write a number, a date, a count, or a "nothing/never/already" about current state,
and the source is a note, a summary, a banner, or your own earlier message. Stop and run something.

## What this does NOT cover

Durable knowledge — law, doctrine, decisions, hard-won lessons — is exactly what memory is for and
does not need re-deriving. The line: **memory holds how we work; files hold what happened.**
